## Cómo firmar

La firma se hace una sola vez, en un pull request, mediante *CLA Assistant*
([cla-assistant.io](https://cla-assistant.io)). En tu primer pull request contra `master` la app
publica un comentario con un enlace a este Acuerdo y a la página de firma. Abres ese enlace,
autorizas con tu cuenta de GitHub y aceptas el Acuerdo ahí; la firma queda registrada contra tu
cuenta de GitHub y la versión del texto anterior (esa versión se publica también como Gist, idéntico
byte a byte a este archivo). La app pone entonces en verde el check de estado `license/cla`, lo que
permite a un mantenedor revisar y mergear el pull request. La firma cubre tus Contribuciones actuales
y futuras al Proyecto hasta que se publique una nueva versión de este Acuerdo, momento en el que se
te pedirá firmar de nuevo. El mantenedor puede registrar tu cuenta de GitHub como usuario permitido
para la automatización del repositorio que no deba interrumpirse.

Si contribuyes en nombre de un empleador u otra persona jurídica, escribe a
[info@nextechsolutions.mx](mailto:info@nextechsolutions.mx) antes de firmar para acordar el
instrumento adecuado.
