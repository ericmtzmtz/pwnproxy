## How to sign

Signing is done once, on a pull request, through *CLA Assistant*
([cla-assistant.io](https://cla-assistant.io)). On your first pull request against `master` the app
posts a comment with a link to this Agreement and to the signing page. You open that link, authorize
with your GitHub account, and accept the Agreement there; the signature is recorded against your
GitHub account and the version of the text above (this version is also published as a Gist,
byte-identical to this file). The app then sets the `license/cla` status check green, which allows a
maintainer to review and merge the pull request. The signature covers your current and future
Contributions to the Project until a new version of this Agreement is published, at which point you
will be asked to sign again. The maintainer can record your GitHub account as an allowed user for
repository automation that must not be interrupted.

[info@nextechsolutions.mx](mailto:info@nextechsolutions.mx) before signing so that the appropriate
agreement can be arranged.
